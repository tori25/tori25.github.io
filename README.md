# Vera Mezhvynskiy — Personal Site

My personal website, hosted on GitHub Pages at **https://tori25.github.io**.

It has my data science and software development portfolio, my resume, and my cover letter. It also has a page about the book *The Brain That Changes Itself* by Norman Doidge.

## What's on the page

- **Header**: my name and title, with buttons for Projects, Resume and Cover Letter
- **Data Science Projects**: cards that link to my project code on GitHub
- **Book section**: quotes, key ideas about brain plasticity and a short summary

## Built with

- HTML5 and CSS
- Bootstrap 4
- JavaScript with [ScrollReveal](https://scrollrevealjs.org/) for the scroll animations
- Font Awesome icons and Google Fonts (Cardo, Lora)
- GitHub Pages with Jekyll (`_config.yml`, `Gemfile`)

## Files

| File | What it is |
|------|------------|
| `index.html` | The main page |
| `style.css` | The page styles |
| `resume.pdf` | My resume |
| `cover_letter.pdf` | My cover letter |
| `_config.yml` | Jekyll / GitHub Pages settings |
| `Gemfile` | Ruby gems for GitHub Pages |

## Run it locally

Open `index.html` in your browser.

Or, to run it with Jekyll like GitHub Pages does:

```bash
bundle install
bundle exec jekyll serve
```

Then go to http://localhost:4000.
